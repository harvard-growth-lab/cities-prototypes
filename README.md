A shared repository for housing prototypes related to the 2026-2027 Bloomberg Cities project.

- `app/` — the production React app: Nil's `cities-v-1` design rebuilt on shadcn/ui + Tailwind and
  driven by the City Atlas data (see `app/README.md` for setup, the data pipeline and what was kept
  from the prototype)
- `nt-prototypes/` — earlier single-file HTML prototypes

The design prototypes (`cities-v-1` … `cities-v-4`) live on `main`, which GitHub Pages publishes.
